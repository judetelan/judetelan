## hi, i'm jude

I build things because it's fun. Most of the time I'm poking at something until I get how it works, breaking it, then fixing it.

I'm still learning. Pretty much everything, honestly. Every day still goes to show that there's something new to learn. No fancy stuff. I also teach other people what I've picked up so far.

<br>

## how I got here

I had no software background. I started learning AI in 2025 and never formally learned Python or any other language. This is roughly the order things happened in:

- A few Coursera courses (listed below), to figure out what these tools are and how to talk to them
- [Flowise](https://github.com/FlowiseAI/Flowise) for chaining models and prompts together (it's archived now)
- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) for running image models myself instead of through an app
- [n8n](https://github.com/n8n-io/n8n), which is where I learned to move data through automations
- A detour into GTM engineering with Clay. It didn't stick. I'd rather build the system than be the one selling.
- Claude Code and MCP servers, so my tools can talk to each other

The thing I took away from all of it is handling data. Take something in, process it, put structured data out. Most of what I build comes down to that loop.
